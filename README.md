# Mushroom Radar

A GitHub Pages-ready prototype for visualizing mushroom-fruiting forecasts across Southwest Colorado.

## Included features

- Mushroom search and detailed habitat-learning guide
- 7-day NWS weather-station conditions and 7-day weather outlook
- Terrain overlays for slope, aspect, and hillshade (USGS 3DEP)
- Ranked best-spots list
- Recent public fungus sightings from iNaturalist
- Private, browser-only foraging journal
- Photo capture checklist and safety reminder
- Browser-only condition reminder
- Installable/offline-ready app shell on GitHub Pages

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

1. Create a repository named `MushroomRadar` and upload these files to its `main` branch.
2. In **Settings → Pages**, choose **Deploy from a branch** and select `main` / `/ (root)`.
3. Wait for GitHub to display the public site URL.
